The one instruction, a b c: memory[b] −= memory[a]; if the result is 0 or less, go to c, else to
      the next instruction. With b = −1 (out) it prints memory[a] instead, and a jump to a negative address
      stops. Words are 16 bits. A missing c means the next instruction either way.

    
The gates are NOT, OR, the full adder's sum and carry, and "choose" (a ? c : b), written by the 35k gate model
      from their truth tables and checked row by row. The subtractor (x + NOT y + 1, a digit at a time), the "0 or less" test
      and the jump are made of them alone. Inputs here: a = 3, b = 5, c = 7, d = 11, e = 13.
