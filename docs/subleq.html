SUBLEQ playground

Code, models and training on GitHub

Two tiny transformers run here, in your browser, 34,976 parameters each (15 KB, layer weights −1, 0 or +1). The gate model writes the five logic gates this one-instruction computer is built from; the program model writes its programs, and longer arithmetic is compiled into steps it writes.

The one instruction, a b c: take memory[a] from memory[b]; if that leaves 0 or less,
          go to c, else to the next line (no c: the next line either way). With out as b it prints
          memory[a]; a jump to −1 stops. z holds 0, one 1, and the inputs are a = 3, b = 5,
          c = 7, d = 11, e = 13. It multiplies and divides by counting down, so a number it counts must not be below 0.

      

    

  


  

    
Each gate is asked for by its name and truth table, in grey; the gate model writes the rest. The
      computer on the other tab is built from these five, as written here, and from nothing else.

    

    

      
      
    

    
How: x − y is x + NOT y + 1, a NOT, a sum and a carry a digit (48 gates); 0 or less, the top digit
      OR no digit set (18); the next instruction, pc + 3, a sum and a carry a digit (32); the jump, a choose a digit
      (16): 114 gates a step, 16 digits each.
